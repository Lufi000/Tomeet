# 《情绪鸡尾酒》多巴胺章节 · 讲书稿正文

咱们先说第一种物质，多巴胺。这一章听完，你生活里一大半的"为什么"就有答案了——为什么明明很累还要刷手机到半夜，为什么追完一部剧心里空落落的，为什么孩子写作业非得拿奖励哄着才肯写。

多巴胺是什么？用咱们能听懂的话说，多巴胺就是一种"我想要"的感觉。注意啊，它不是快乐本身，它是想要快乐的那股劲儿。

那它为啥这么设计呢？作者把我们带回两万五千年前。你有个祖先，书里管他叫邓肯。有天早上他饿醒了，想起不远的沼泽地里有金黄的云莓。就这一想，多巴胺"唰"地上来了，他钻灌木丛都不觉得累。结果到了一看，云莓被摘光了，多巴胺瞬间掉光，那个空虚啊。可这时候他发现远处有个苹果——多巴胺又来了，他爬树摘果，吃得那叫一个美。关键在后面：吃完没一会儿，多巴胺掉得比吃之前还低。为什么？大脑就是要让他难受，难受了他才会去找第二个苹果，才会囤食物、修房子、为过冬做准备。你看，多巴胺不是让你享福的，是让你活下去的。

这个机制放到今天会出什么问题呢？书里引用了斯坦福休伯曼教授的研究，讲了个特别重要的概念，多巴胺基线。啥意思呢？用1到10打分，你的基线是5。刷到一个好玩的视频，升到6。可视频一结束，它不是回到5，是掉到4.9。为什么？大脑故意的，就是要让你心里痒痒，"继续找啊"。你再刷一个，从4.9出发，只升到5.9，又掉到4.8。一个接一个，等你放下手机，基线已经掉到4了。你们有没有过这种体验？晚上刷短视频，刷的时候挺爽，放下那一刻，比刷之前还累还空。就是这个原理，你被自己的多巴胺算计了。

那有没有例外？有。同样是看视频，看真正激励人心的内容，看完反而更有劲。所以作者简单粗暴地分两种——他自己坦白说，这分法不严谨，但说出来大家能听懂——快多巴胺和慢多巴胺。就像快碳水和慢碳水：白米饭、糖，升得快掉得也快；糙米、杂粮，顶饱还稳。巧克力、短视频、刷股票是快多巴胺；读书、学习、锻炼是慢多巴胺。慢的管将来，快的只管当下这一口。

为啥我们老选快的？因为大脑最恨多费能量，能量是进化里最值钱的货币。作者在商场观察过，绝大多数人下楼都坐自动扶梯，没人走楼梯。这不是你懒，是两万五千年前的本能。

更麻烦的是，现在有帮聪明人专门收割你的多巴胺，作者叫他们"多巴胺盗贼"。游戏公司、短视频平台，雇心理学家研究用什么颜色、什么声音让你离不开。你的时间就是他们的钱。你想过没有，盲盒为啥这么火？拆开之前那种抓心挠肝的期待，就是多巴胺在飙升——商家卖的不是玩具，是你拆开前那股劲儿。孩子的软件更是重灾区，作者说，今天最卑鄙的事是"从婴儿身上偷多巴胺"。

好，道理讲完，上工具。这书的好处就是工具多，多巴胺这章给了十个，前六个教你管住快多巴胺，后四个教你给自己加油。一个一个来。

第一个工具，拒绝多巴胺堆积。什么叫堆积？你看剧觉得不够爽，加包爆米花；还不够，一边看一边刷手机；再不够，电视开着当背景音。一层一层往上叠。这有三个问题：一是没有自然终点；二是大脑习惯了高刺激，到该专注的时候它也要，比如开车忍不住摸手机——作者给了个数据，太吓人了，就因为这个，全世界车祸率上升了百分之十到三十；三是叠到最后，你连安安静静看完一部片子都做不到。书里举了个例子，1942年《卡萨布兰卡》上映，全场凝神静气看完；搁今天，让人不带手机看完它等于折磨人。怎么办？一次只做一件事，同一时刻只留一个多巴胺来源；实在不行上"冷火鸡"法，十到三十天彻底戒断快多巴胺。注意，这不叫"多巴胺排毒"，多巴胺不是毒，你要改的只是只求快满足的习惯。

第二个工具，保持多巴胺平衡。作者自己的比例是快多巴胺和慢多巴胺二比八，他说这是大多数人的最佳平衡点。还有个特别实用的建议：早上起来别先看手机。你想啊，一睁眼，几十条消息、热搜"轰"一下灌进来，快多巴胺直接拉满，这一天你都不想做慢的正经事了。再把通知全关了。通知对渴望多巴胺的人，就像在饿肚子的人面前晃一袋薯片，你忍不住的。

第三个工具，适度分配多巴胺。听着玄乎，其实就是"省着点用"。作者举了个听歌的例子，一首新歌单曲循环，越听越爱，突然有一天，没感觉了。你要是把间隔拉长，这首歌能保鲜很久。咱们小时候都有这体验，对吧？看动画片，一个星期才一集，周六晚上守着电视，一礼拜都有盼头。现在的孩子打开平板啥都有，想看几集看几集，反而看完心里空落落的。作者还有个极端习惯，看剧故意拖着不看最后几集，靠脑补结局来获得多巴胺。你不用学这么狠，学他那个劲儿就行：看完一集，回味回味，猜猜后面，再看下一集。另外，干成一件大事，别把庆祝一次用完，项目结束后连续一星期每天搞个小仪式，把喜悦摊开来享受。

第四个工具，分清内源性和外源性多巴胺。这个每个家长都用得上。斯坦福做过个实验，有点残酷。幼儿园孩子本来都爱画画，画得开心，这是内在动机。然后研究人员开始发奖，画一幅给一个"优秀小画家"奖，孩子高兴坏了。结果有一天，奖突然不发了。你猜怎么着？孩子们不画了。本来为爱画画的孩子，变成只为奖品画画的孩子，奖品一撤，两个动力全没了。你想想咱们辅导作业，是不是天天犯这个错？"写完作业奖励玩半小时手机。"一开始管用，慢慢的，没手机他一个字都不写——内驱力被你的奖品换走了。那怎么办？让过程本身成为动力。去健身房，别惦记练完奖励自己奶茶，去感受练的时候浑身是劲的状态。你的前额叶皮质，是可以学会在过程中找到乐趣的。

第五个工具，丰富多巴胺来源。灵感来自游戏。游戏为啥让人上瘾？因为"差一点就赢"比"大胜"释放的多巴胺更多。用到生活里，就是给自己制造随机性。作者随身带骰子，常去的咖啡馆，掷到六才去，其他点数换一家。他跟表弟公路旅行，每个岔路口掷骰子定方向，最后在蚊子成堆的沼泽地露营，却成了他这辈子最难忘的旅行。咱们可以变通着用，周末不知道带孩子去哪儿，写几个纸条抓阄，孩子准兴奋。还有个研究特别逗，让人用筷子吃爆米花、用马提尼酒杯喝水，结果爆米花更香了，水都更好喝了。用新方式做一件司空见惯的事，多巴胺立刻上来。

第六个工具，避免多巴胺宿醉。最常见的就是周末。工作日多巴胺被吊着，周末一闲下来，落差太大；或者反过来，周末快多巴胺吃到撑，周一回工位，那个落差能要你的命。你们有没有发现，周日晚上特别容易emo？八九点钟，莫名其妙地烦躁、心慌，不想面对明天。这就是多巴胺宿醉。怎么办？第一，知道它是怎么回事，接受它，光是"哦，我这是多巴胺宿醉"这个念头，就能让你好受不少。第二，周末别往死里堆快多巴胺，多安排散步、晒太阳、健身、下棋、见朋友这些慢多巴胺活动。

好，前六个是"管住"的工具，后四个是"加油"的工具，教你没动力的时候给自己来一针多巴胺。

第七个工具，找出情绪动因。作者的儿子九岁时死活不肯背乘法表。后来他妈开了个咖啡馆，孩子想去打工收账，他妈说行啊，但你得先会乘法，不然客人买三根棒棒糖你算不明白。这孩子立刻明白了背乘法表是干嘛的。这就是情绪动因——给任务找一个带着真实情感的"为什么"。作者自己不想健身时，就想起他爸，因为长期不锻炼，晚年三次心脏病发作，遭了十五年的罪。这段回忆就是他最强的动力。他还支了一招：想要什么，先尝尝。孩子想养兔子但攒不够钱，他就借了两只回家养一个周末再还回去。孩子尝到那个滋味，三个星期就把钱挣够了。

第八个工具，冷水浴。有硬数据：《欧洲应用生理学杂志》的研究，14度的水泡60分钟，多巴胺提高百分之二百五，而且是缓缓上升的。咱们不用那么狠，早上冲个凉，或者冬天用冷水洗把脸，都有用。你看那些坚持冬泳的大爷大妈，精神头一个比一个好，人家那是有科学道理的。

第九个工具，制作愿景板。人忘性大，梦想一想挺激动，转头就忘了。所以你把它做出来：一张大纸，贴上你想要的生活的图片，写上你想成为什么样的人，挂在刷牙能看到的地方，天天看，沉浸式地想，多巴胺实时就给你。其实咱们中国人早会这招。越王勾践卧薪尝胆，每天尝一口苦胆，提醒自己别忘了要干什么——那就是一个挂起来的愿景板。

第十个工具，保持动力。动力这东西能自我繁殖。你坚持去健身房一段时间，看到效果，效果反过来推着你继续去，引擎就自己转了。怕就怕断档——生个病、休个假，回来再也找不着状态。怎么办？别等动力来了才行动，是先行动起来，动力才跟着来。这个我们讲《原子习惯》那本书的时候也说过，记得吗？把启动门槛降得越低越好，鞋带一系，人站上跑步机，剩下的交给多巴胺。

好，把这一章收一下。多巴胺不是快乐，是一种"我想要"的劲儿。它分快慢，快的像糖，慢的像杂粮饭，你的鸡尾酒里慢多巴胺得是主料。快多巴胺可以有，生活不能没乐趣，但你得管住它：别堆积，别一大早灌满，别一次吃光，别让外面的奖励换掉你的内驱力。没动力的时候怎么办？找情绪动因、冲冷水、看愿景板、先动起来再说。以上是多巴胺，很重要。
