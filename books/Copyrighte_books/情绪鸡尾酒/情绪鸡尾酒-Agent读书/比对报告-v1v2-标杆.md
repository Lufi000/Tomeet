## 四、Skill 变更清单（沉淀到 `~/.claude/skills/book-talk-script/`）

1. **SKILL.md**
   - 区分**联想 vs 注水**：评论观点=禁；为概念配听众世界里的例子（个人经历/本土类比/中国场景/交叉引用）=必须，每概念至少 1 个非原书例子
   - **工具全保留**原则：工具书的方法/工具不清单化裁减
   - **正文单元配方**：降维定义→原理→工具逐个讲→绕回重申
   - 长度标准：15000-20000 字 / 45-60 分钟（原 7000-9000 字是"精华版"不是节目）
   - 口头语**密度量化**："对吧"每千字 3-4 次等，写完数一遍
   - 樊登式收束：自查清单→基本盘（交叉引用带过）→金句
   - 常见错误表 +6 条、自检清单 +6 项
2. **新增 reference/fandeng-style.md**：标杆风格参考，6 组带手法拆解的真实摘录 + 反例对照表
3. **jiangshu agent**（`~/.claude/agents/jiangshu.md`）：默认时长 7000-9000 字 → 15000-20000 字；成稿前必读 fandeng-style.md

## 五、遗留差距（有意保留，不再迭代）

1. **节目运营模板未模仿**：标杆开头报录制地点（长春吉云轩书店）、结尾分享呼吁+下期预告。这是帆书节目模板，不是讲书方法，独立讲书稿不需要。
2. **第一人称体温有限**：标杆的例子带真实身份细节（"我们家有个老人""我在电视台迷茫那阵子"）。v2 有一处仿写（迷茫期社交），但 agent 没有真实人生，这层体温是讲书人 IP 素材库才能解决的，超出 skill 能力边界。
3. **标杆转写错别字未学**（皮脂醇/内肺态等语音识别误差）——只学讲法不学文字。

## 六、结论

v2 在结构、工具覆盖、例子来源、长度、口吻密度五个维度全部进入标杆区间，判定**满意，停止迭代**。skill 的进化已沉淀，后续用 jiangshu agent 讲任何书都会自动应用这套标准。
